# Без пауз… только Бас…. Wayne and Del — комикс-клип (Sin City, Ч/Б + красный)

Клип в стиле **Sin City / noir comic** на песню Андрея **«Без пауз… только Бас…. Wayne and Del»** ([Suno](https://suno.com/song/c79f7fc5-e67f-48a2-8cf0-c9963f7530d2)).

## Как сделано

- **Музыка и текст** — Андрей, Suno (текст — [lyrics.txt](lyrics.txt); EDM / Wayne and Del).
- **8 страниц комикса** сгенерированы ИИ — в папке [pages/](pages/) (page05 повторно использует page02 для Pre-Chorus 2; page07 повторно использует page03 в начале финального припева, page08 — финал/outro).
- **Клип** 1280×720, 25 к/с, 3:38: страницы с мягкой «камерой» сменяются в такт куплетам, внизу неоновый эквалайзер без свечения.
- **Персонажи вымышленные**, без логотипов, эмблем и сходства с реальными людьми.
