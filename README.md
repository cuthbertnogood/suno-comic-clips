## Очередь загрузок

Сводная таблица: [QUEUE.md](QUEUE.md).

Статусы: **в очереди на комикс** → **комикс готов** → **загружено YouTube** → **загружено Rutube**.

Кто что делает: Suno2 рисует комиксы, Suno (Grok Bot) загружает их на YouTube (CutNoGood, не больше 6 в день), агент Rutube загружает на Rutube.

## Обложки

Каждый новый трек получает обложку в `covers/NN_<slug>.jpg` (~640px, jpg) и колонку «Обложка» в QUEUE.md. Обложку добавляет Suno2, когда заканчивает комикс (кадр из клипа), или Suno (Grok Bot) при загрузке; для треков в очереди — обложка Suno.

## Исходники песен (обязательно)

Каждая папка песни `NN_slug/` обязана содержать:
- `lyrics.txt` — текст песни;
- `suno_prompt.md` — запрос на генерацию в Suno (Title, Style, Lyrics в том виде, как отправлены в Suno; вывод Song_text_gen).

Оба файла также прикладываются ассетами к GitHub-релизу песни (`gh release upload <tag> lyrics.txt suno_prompt.md --clobber`). Если исходный запрос не сохранился, это помечается в README папки — текст не выдумывается.
