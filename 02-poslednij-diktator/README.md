## Как сделано

- **Музыка и текст** — Андрей, песня создана в Suno (текст — см. [lyrics.txt](lyrics.txt)).
- **29 страниц комикса** сгенерированы ИИ по структуре и смыслу песни — лежат в папке [pages/](pages/).
