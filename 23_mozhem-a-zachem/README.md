# Можем, а зачем? — комикс-клип (Sin City, Ч/Б + красный)

Клип в стиле **Sin City / noir comic** на песню Андрея **«Можем, а зачем?»** ([Suno](https://suno.com/song/9e7d4ebf-e2b9-4271-98f4-30d35c1699ee)).

## Как сделано

- **Музыка и текст** — Андрей, Suno (текст — [lyrics.txt](lyrics.txt)).
- **6 страниц комикса** сгенерированы ИИ — в папке [pages/](pages/).
- **Клип** 1280×720, 25 к/с, 2:44: страницы с мягкой «камерой» сменяются в такт куплетам и припевам, внизу неоновый эквалайзер без свечения.
- **Персонажи вымышленные**, без логотипов и реальных брендов. Эмблемы на решётке «жигуля» замазаны (в т.ч. на странице бриджа / дача).
- В этой записи после 2-го куплета сразу идёт бридж (средний припев пропущен), поэтому страницы идут: куплет → припев → куплет → бридж → припев → финал.
