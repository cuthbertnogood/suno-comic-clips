# Кощеева защита — комикс-клип (Sin City, Ч/Б + красный)

Клип в стиле **Sin City / noir comic** на песню Андрея **«Кощеева защита»** ([Suno](https://suno.com/song/31228c2e-bdbd-4826-819f-171e16ec58df)).

## Как сделано

- **Музыка и текст** — Андрей, Suno (текст — [lyrics.txt](lyrics.txt); сатирический фолк-панк).
- **10 страниц комикса** сгенерированы ИИ — в папке [pages/](pages/) (по одной на каждый отрывок ~15–20 с).
- **Клип** 1280×720, 25 к/с, 2:40: страницы с мягкой «камерой» сменяются в такт куплетам, внизу неоновый эквалайзер без свечения.
- **Персонажи вымышленные**, без логотипов, эмблем и сходства с реальными людьми. На страницах 3 и 5 нижние служебные подписи («ПРЕ-ХОРУС», «Verse 2») закрашены чёрным.
