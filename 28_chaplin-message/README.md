# Charlie Chaplin - A message to humanity (russian version) — комикс-клип (Sin City, Ч/Б + красный)

Клип в стиле **Sin City / noir comic** на песню Андрея **«Charlie Chaplin - A message to humanity (russian version)»** ([Suno](https://suno.com/song/63efd42e-90ad-4db3-b7b9-047f0e085eef)).

## Как сделано

- **Музыка и текст** — Андрей, Suno (текст — [lyrics.txt](lyrics.txt); spoken-word монолог по мотивам речи Чаплина).
- **7 страниц комикса** сгенерированы ИИ — в папке [pages/](pages/) (page06 повторно использует page04 для третьего блока «Солдаты!»).
- **Клип** 1280×720, 25 к/с, 7:58: страницы с мягкой «камерой» сменяются по смыслу монолога, внизу неоновый эквалайзер без свечения.
- **Персонажи вымышленные**, без логотипов, эмблем и сходства с реальными людьми. На page05 красные нарукавные повязки солдат закрашены в однотонные тёмные (без символов).
