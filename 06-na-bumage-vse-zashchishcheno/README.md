# «На бумаге всё защищено» — комикс-клип

Комикс-клип по песне Андрея «На бумаге всё защищено» (5:38): сатирическая диалоговая песня о совещании чиновников после катастрофы с ЦОДами.

**Стиль:** Sin City / нуар-комикс — чёрно-белая графика с красными и голубыми (cyan) акцентами. Страницы комикса сменяются в такт тексту, поверх идёт радужный эквалайзер.

**Страниц:** 28.
